점검 준비 중

매달 하는 일 — 순서대로 5단계

평상시에는 「캘린더」 탭만 쓰면 됩니다. 「입력·설정」은 과거 기록을 한꺼번에 고치거나 직원·공휴일 같은 기준정보를 바꿀 때만 들어가십시오.
순서할 일어디서방법
1기준월을 다음 달로맨 위 「기준월」 「익월 ▶」 버튼을 한 번 누릅니다.
2연차·대휴·대체근무 지정캘린더 날짜를 클릭하면 아래에 그날 근무자 목록이 나옵니다. 해당 직원 줄에서 연차·교육·공가·대휴 버튼을 누르면 끝입니다.
대체근무는 부재가 생긴 사람 줄에서 옆 목록으로 대신 근무할 사람을 고르고 「대체지정」을 누릅니다. → 부재기록까지 함께 만들어지고, 구분·스케줄·대휴시간은 자동 계산됩니다.
3검증 확인입력·설정 맨 위 검증 결과가 오류 0건인지 봅니다. 탭 이름에 숫자가 붙으면 오류가 있다는 뜻입니다. 「확인」 항목은 예외 처리라면 그냥 두어도 됩니다.
4결재본 확정결재 관리 「당초 계획 확정 (제1차)」를 누릅니다. 이후 내용이 바뀌면 자동으로 「변경됨」이 뜹니다.
5PDF 저장 · 백업맨 위 버튼 「근무편성 묶음 → PDF」 와 「보안담당자 지정 → PDF」 를 각각 눌러 2개 파일로 따로 저장합니다. 자료는 서버에 자동 저장되므로 따로 할 일은 없습니다. 월말 결재 뒤에 💾 백업으로 JSON 파일을 한 번 받아 두면 안전합니다.
6붙임 엑셀 받기맨 위 📊 붙임 엑셀 기존 제출 서식 그대로 근무편성표(기간별) · 근무일정표 · 대체근무 편성표 · 대휴명부 가 시트로 나뉘어 한 파일로 저장됩니다. 공문 붙임으로 바로 첨부하시면 됩니다.
인쇄창에서 대상: PDF로 저장, 배율: 기본, 배경 그래픽 체크로 저장하십시오. 용지 방향(가로/세로)은 문서마다 자동으로 잡힙니다.

월 중에 내용이 바뀌면 (재결재)

순서할 일방법
1캘린더에서 수정 바뀐 날짜를 클릭해 고칩니다. 되돌릴 때는 「해제」 버튼.
2변경 확정 「결재 관리」에 “결재 후 N건 변경됨”이 뜹니다. 「변경 확정 (제2차)」를 누르면 변경 대비표가 자동으로 만들어집니다.
3재결재 상신 변경 대비표가 묶음 PDF에 함께 들어갑니다 (「입력·설정 → 출력 설정」에서 변경 대비표가 체크되어 있어야 합니다).
변경 대비표에는 일자·성명·배치·당초·변경·구분이 자동으로 채워집니다. 따로 작성할 필요가 없습니다.

인사이동이 있을 때 — 「배치 이력」 탭

상황쓰는 기능입력 내용
한 날짜에 여러 명이
동시에 바뀜		일괄 재배치 효력일을 넣고 바뀌는 사람만 새 배치를 고른 뒤 적용. 나머지는 「유지」로 두십시오.
한 명만 바뀜
(일근 ↔ 교대조, 사무실 ↔ 현장)		배치 이력 효력일·대상자·배치를 한 줄 추가합니다. 그 날짜부터 다음 기록이 나올 때까지 유효합니다.
두 사람이 한시적으로
자리를 맞바꿈		임시 조교체 한 줄이면 끝입니다. 시작·종료일과 두 사람만 넣으면 양쪽 배치 전환 + 기간 종료 후 복귀 + 근무지정표 분할 + 비고까지 자동 처리됩니다.
휴직·파견휴직 · 파견 기간을 넣으면 그 기간 편성에서 빠지고 현원도 자동으로 줄어듭니다.
소장(일일보안 관리책임자)은 배치와 별개입니다. 인원이 부족해 교대근무로 갔다가 돌아와도 관리책임자는 그대로 유지됩니다. 「입력·설정 → 직원 명부」의 소장 체크로 지정합니다.

탭별 쓰임새

탭구분용도
캘린더입력 + 출력매달 여기서 입력합니다. 월 근무 현황을 한눈에 봅니다.
근무지정표출력배치가 바뀌는 날을 찾아 기간별로 자동 분할해 만듭니다.
근무일정표출력인원 × 일자 표. 교대 순환·대체근무·대휴·부재가 모두 반영됩니다.
대체근무 편성표출력연 누적(기준월까지). 대휴일·사용시간·잔여가 자동 배정됩니다.
대휴 원장출력개인별로 발생 ↔ 사용을 짝지어 보여주고 잔액·사용가능일수를 계산합니다.
대휴명부출력이월 + 발생 − 사용 = 잔여. 전월 잔여를 옮겨 적을 필요가 없습니다.
보안담당자 지정출력(별도)일자별 주간·야간 담당자 자동 배정. 별도 PDF로 저장합니다.
월별 누적출력연간 추이. 내부평가·보고 자료로 그대로 씁니다.
결재 관리관리당초·변경 결재 차수 관리, 변경 대비표 생성.
배치 이력관리인사이동이 있을 때만 들어갑니다.
입력 · 설정관리검증 결과 확인, 과거 기록 일괄 수정, 직원·이월·공휴일·출력 설정.

자료 저장 위치

SkyWatch 서버에 저장됩니다. SkyWatch 메뉴 「근무편성」으로 열면 어느 PC에서나 같은 자료가 보입니다. 로그인한 근무자는 누구나 고칠 수 있습니다.
항목내용
저장 상태맨 위 오른쪽에 「서버에 저장됨 (시:분)」이 보이면 저장된 것입니다. 빨간 「저장 안 됨」이 보이면 창을 닫지 말고 안내대로 [다시 저장]을 누르십시오.
다른 근무자와 같이 고칠 때다른 근무자가 먼저 저장했으면 내 저장은 막히고 「다른 근무자가 먼저 고쳤습니다」가 뜹니다. 필요하면 내 화면을 JSON으로 받아 두고 최신 자료를 다시 불러오십시오.
잘못 고쳤을 때「입력·설정 → 데이터 관리 → 직전 판으로 되돌리기」로 직전 판 (가장 최근 통째 변경(복원·비우기) 전, 또는 약 10분 이상 쉬었다가 고치기 시작하기 전의 판)으로 돌아갑니다. 그보다 앞이면 💾 백업 JSON을 📥 복원합니다.
처음 옮기기 (한 번)예전 근무편성 HTML 파일을 열어 💾 백업으로 JSON 파일을 받은 뒤, 이 창에서 📥 복원으로 올립니다. 올린 뒤에는 모든 근무자가 같은 자료를 봅니다.
권장 브라우저Chrome 또는 Edge 110 버전 이상. 110 미만이면 문서별 용지방향(가로/세로)이 자동으로 바뀌지 않아 인쇄창에서 직접 지정해야 합니다. 인터넷 익스플로러에서는 동작하지 않습니다.
글꼴문서 제목에 「HY헤드라인M」(한글 프로그램 설치 시 포함)을 쓰며, 없으면 기본 고딕으로 대체됩니다. 사용에는 지장이 없습니다.

자주 묻는 것

질문답
매달 입력·설정에 값만 넣으면 되나? 아닙니다. 매달 하는 입력은 캘린더에서 클릭으로 끝냅니다. 입력·설정은 ① 검증 결과 확인 ② 과거 기록 일괄 수정 ③ 직원·이월·공휴일 같은 기준정보 변경 때만 씁니다.
주/야/비/휴는 안 넣어도 되나? 넣지 않습니다. 4조 2교대 순환과 배치 이력에서 전부 자동 계산됩니다. 넣는 것은 예외(연차·대휴·대체근무·부재)뿐입니다.
대체근무 대휴시간은 얼마로? 자동 계산됩니다. 주간 8h / 야간은 대체자가 일근이면 16.5h, 교대면 11h. 예외 상황이면 표에서 직접 고칠 수 있고, 자동값과 다르면 검증에서 알려줍니다.
대휴는 몇 시간 단위로? 8시간(1일) 단위입니다. 16.5h 발생분은 2일 쓰고 0.5h가 남으며, 이 소수 잔여는 합산되어 잔액에 포함됩니다. 캘린더에서 대휴를 누르면 잔액이 모자랄 때 경고합니다.
전월 잔여 대휴를 옮겨 적어야 하나? 아닙니다. 연간 기록이 하나로 누적되어 있어 기준월만 바꾸면 그 시점 잔액이 자동으로 나옵니다.
해가 바뀌면? JSON 백업 후 새 연도의 「연초 이월 대휴 시간」과 「연차 부여일수」를 입력하세요. 연도별로 따로 보관됩니다.
자료가 없어지지 않나? 서버에 저장되므로 PC·브라우저를 바꿔도 그대로입니다. 잘못 고친 것은 직전 판으로 되돌리고, 그보다 앞은 💾 백업 JSON으로 복원합니다.
인터넷 없이 되나? 됩니다. SkyWatch 서버만 켜져 있으면 됩니다. 외부 서버·CDN·글꼴을 불러오지 않습니다.
엑셀 가져오기가 안 될 때 브라우저가 오래된 경우입니다. Chrome·Edge 110 이상으로 여십시오. 나머지 기능은 구형 브라우저에서도 동작합니다.
