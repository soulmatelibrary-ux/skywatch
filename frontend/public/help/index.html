가운데: 새 카드 작성

  1. 과제 선택 — 일회성 카드 (과제 연결 안 함), 🔗 이어받은 일, 📌 장기 과제 중 고릅니다. 왼쪽 목록의 ＋ 이어서 쓰기를 눌러도 자동으로 골라집니다.
  2. 제목을 씁니다(필수).
  3. 본문 — 도구 줄의 항목 넣기(조치·원인·결과·다음 할 일), B, • 목록, 표 넣기, 이미지 넣기(10MB 이하)를 씁니다. 한글·엑셀 표와 캡처 이미지는 붙여넣기(Ctrl+V)로 넣을 수 있습니다.
  4. 연결 — 본문에 #검색어를 치면 다른 카드 링크, #TD:번호는 관제시스템 문서 링크가 됩니다.
  5. 📎 파일 첨부 — 여러 개, 끌어다 놓기 가능, 파일당 20MB.
  6. 분류를 고릅니다(기본 '기타').
  7. 다음 근무가 이어서 해야 하면 🔗 다음 근무로 이어짐을 체크합니다. 새 이어지는 일이 만들어집니다.
  8. 카드 저장. 이미지를 올리는 중에는 누를 수 없습니다. 당일 종료 카드는 완료 상태이고, 🔗 다음 근무로 이어짐 카드는 진행중입니다.
분류 이름에 '문의'가 들어간 카드(예: 문의사항/요청사항)를 완료로 저장하면 문의사항 메뉴에도 한 건이 자동으로 등록되고 "문의사항 메뉴에도 등록했습니다 (H번호)" 알림이 뜹니다. 이어지는 일(진행중) 카드는 그 일을 종료할 때 등록됩니다. 자세한 기본값은 문의사항 참고.

가운데: 📨 전달·메모

카드로 쓸 정도가 아닌 한 줄 전달입니다. 종류(전달사항·행정·기타) → 내용(255자) → 받는 사람(다음 근무 / 근무자 전원 / 특정인) → 유지(확인할 때까지 / 다음 근무에만 / 7일간) → 메모 저장 또는 Enter.

가운데 아래: 이 근무의 카드

저장한 카드 목록입니다. 모두 펼치기 / 모두 접기, 읽기 화면 ›(일지 보기로 이동).

카드 고치기·지우기

오늘 근무뿐 아니라 어제·그제 등 최근 7일 근무의 카드도 같은 방법으로 고칩니다(위의 최근 7일 근무 ▾ 또는 ◀ ▶). 7일이 넘은 근무는 “오래된 근무입니다” 안내만 나오고 고칠 수 있습니다.

  1. 카드 줄 오른쪽의 ✎ 수정(펼친 카드 아래의 수정)을 누르면 그 자리에서 수정 중 상자가 열립니다. 한 번에 한 장만 고칠 수 있습니다.
  2. 분류·제목·본문(표·이미지·#카드 링크 포함)을 고치고 수정 저장(Ctrl+Enter)을 누릅니다. 저장하면 카드 줄에 수정 이름 시각이 표시됩니다. 첨부 파일은 여기서 바꿀 수 없습니다.
  3. 다른 근무자가 쓴 카드는 상자에 작성자가 표시되고, 저장 전에 한 번 확인합니다. 고치면 이전 내용은 남지 않고, 이 근무 일지를 만든 사람(카드를 쓴 사람과 다를 수 있습니다)에게 수정 알림이 갑니다. 그 사람이 직접 고칠 때는 알림이 없습니다. 그 사이 다른 사람이 같은 카드의 제목·본문·분류를 바꿨다면 덮어쓸지 물어보고, 상태 변경처럼 내용이 그대로인 경우는 묻지 않습니다.
  4. 이어짐 바꾸기 — 당일 종료 ↔ 🔗 다음 근무로 이어짐. 이어짐으로 바꾸면 이 카드로 새 이어지는 일이 만들어져 카드가 진행중이 되고, 당일 종료로 바꾸면 이 카드만 일에서 빠져 완료가 됩니다(카드 하나뿐인 일이면 그 일이 종료됩니다). 장기 과제 카드는 과제 화면에서 바꿉니다.
  5. 카드 삭제(수정 상자 왼쪽 아래)는 확인 문구를 본 뒤에만 지워지고, 삭제한 카드는 이 화면에서 되살릴 수 없습니다(관리자가 DB 에서 삭제 표시를 되돌려야 하며, 이어지는 일에서 빠진 연결은 돌아오지 않습니다). 이어지는 일의 카드를 지우면 그 일에서 빠지고, 마지막 카드였다면 그 일은 종료됩니다. 삭제 알림은 가지 않습니다.
  6. 취소·Esc — 고친 내용이 있으면 내용 버리기를 한 번 더 눌러야 닫힙니다. 수정 중에 다른 근무·메뉴·링크로 이동하려 하면 저장하지 않고 이동할지 묻습니다(계속 수정 / 버리고 이동). 새로고침·창 닫기도 경고가 나옵니다. 다만 브라우저의 뒤로가기 버튼은 막을 수 없어 저장하지 않은 내용이 사라질 수 있으니, 수정 중에는 누르지 마세요.

문의 카드 자동 등록

근무일지·업무일지에서 분류 이름에 '문의'가 들어간 카드가 완료되면 이 메뉴에 한 건이 자동으로 생깁니다. 기본값: 발생일자 = 그 일지 날짜, 발생시간 = 카드 작성 시각, 접수자 = 카드 작성자, 키워드 = 카드 제목, 상세내용 = 카드 본문, 발생버전 = 가장 최근에 입력된 문의사항의 발생버전, 상태 = 완료, 완료일자 = 완료한 날. 카테고리·관제사(섹터)·PR번호·비고는 비어 있으니 여기서 채웁니다. 진행중·보류 카드는 들어오지 않고, 같은 카드를 다시 완료해도 카드 하나당 한 번만 자동 등록됩니다. 등록 뒤 카드를 고치거나 지워도 문의사항은 그대로 남습니다. 문의등록으로 따로 등록해 겹친 건은 목록에서 확인해 지웁니다.

엑셀로 한꺼번에

엑셀 올리기로 시험확인서 엑셀(.xlsx/.xlsm)을 올립니다. 끌어다 놓아도 됩니다. 확정된 PR 목록에 있는 PR만 연결되고, 목록에 없는 PR 시트는 경고 후 건너뜁니다. 다시 올리면 내 기록만 바뀌고, 다른 근무자의 기록은 그대로입니다.

보고서 PDF

보고서를 PDF 한 파일로 받기에서 전체 근무자 또는 특정 근무자, 체크한 PR만 또는 전체를 골라 PDF 받기. PR마다 책갈피가 붙습니다. PR 한 건은 줄의 보고서 보기 / PDF 받기로 봅니다.

버튼·칸하는 일
거르기전체 PR · 검증 안 한 PR · PASS · REJECT · 미판정 · 보류 · 제외, PR 번호·제목 검색
검증 기록 삭제본인·관리자내 검증 기록 지우기

3. 원본 문서

문서 종류(PR목록·제작사 절차서·테스트절차·수정문서·합의서·납품문서·검증결과·기타)를 고르고 파일 선택 또는 끌어다 놓기(여러 개, 파일당 20MB). 종류별 목록에서 보기(PDF·이미지·txt는 브라우저에서 바로) / 받기 / 삭제.

근무편성 새 창

월간 근무지정표·근무일정표·대체근무·대휴·연차와 결재용 PDF를 만드는 도구입니다. 자료는 SkyWatch 서버에 저장되어 어느 PC에서 열어도 같고, 로그인한 근무자는 누구나 고칩니다.

할 일방법
처음 옮기기 (한 번)예전 근무편성 HTML 파일을 열어 💾 백업으로 JSON 파일을 받은 뒤, 근무편성 창에서 📥 복원으로 올립니다.
다음 달 계획기준월을 다음 달로 → 캘린더에서 연차·대휴·대체 지정 → 결재 관리 당초 계획 확정 (제1차) → 📄 묶음 PDF
그 달 중 변경캘린더에서 고칩니다. 결재 시트가 필요하면 결재 관리 변경 확정 (제2차), 아니면 고치기만 합니다.
저장 확인맨 위 오른쪽 「서버에 저장됨 (시:분)」. 빨간 「저장 안 됨」이면 창을 닫지 말고 다시 저장.
잘못 고쳤을 때입력·설정 → 데이터 관리 직전 판으로 되돌리기(가장 최근 통째 변경 전, 또는 약 10분 이상 쉬었다가 고치기 시작하기 전의 판), 그보다 앞이면 📥 복원으로 백업 JSON.
연차·대체·대휴는 근무편성에서만 입력합니다. 「근무 스케줄」에서는 예전 기록만 보이고, 새로 넣으려면 그 창의 근무편성 열기를 누릅니다. 자세한 사용법은 도구 안 「사용방법」 탭에 있습니다.

통근비 계산 새 창

ERP 근태 엑셀을 올리면 근무자별 통근비 달력과 지급일수가 자동으로 나옵니다. 올린 근태 자료는 달별로 SkyWatch 서버에 쌓이고, 설정·고친 칸과 함께 어느 PC에서 열어도 같습니다. 로그인한 근무자는 누구나 고칩니다.

할 일방법
월 통근비 정리파일 업로드로 그 달 ERP 근태 엑셀 → 확인창에서 저장 → 칸을 눌러 근무코드·지급일 고치기 → PDF 저장 (인쇄)
지난 달 보기파일 없이 위쪽 연·월에서 고릅니다. 같은 달을 다시 올리면 그 달만 새 파일로 바뀝니다(고친 칸은 남음).
달 목록·삭제·기간 합계저장된 달 · 기간 합계 → 저장된 달(보기·삭제) / 기간 합계(시작 달~끝 달, 근무자별·달별 지급일수)
저장 확인맨 위 오른쪽 「서버에 저장됨 (시:분)」. 빨간 「저장 안 됨」이면 창을 닫지 말고 다시 저장.
처음 한 번엑셀을 올린 뒤 설정 → 기본 근무자 → 명단에 추가. 순서와 근무유형을 맞춰 두면 다음부터 그대로 나옵니다.
저장되는 것: 올린 근태 자료(달별, 계산에 쓰는 칸만 — 사번·소속 제외), 표 제목, 설정(기본 근무자·공휴일/휴무일·복무명 약어·코드별 지급여부), 달별 고친 칸·근무자 추가/삭제/순서·비대상.
저장 안 되는 것: 원본 보기에서 고친 값(창을 다시 열면 사라집니다. 계속 남길 수정은 달력 칸에서). 자세한 사용법은 도구 안 도움말에 있습니다.
